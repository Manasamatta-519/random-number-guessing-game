# Random Number Guessing Game

## Task 02 - Software Development Internship

A Python-based game that generates a random number between 1 and 100 and challenges the user to guess it.

## Features

- Generates a random number between 1 and 100
- Accepts user guesses
- Provides "Too high" and "Too low" hints
- Counts the number of attempts
- Handles invalid input
- Displays a congratulations message when the correct number is guessed

## Technologies Used

- Python

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
